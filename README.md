# CloseWren · 结账校验本地 Demo

## 账期与业务确认

顶部“账期管理”显示当前月份。首次使用从已导入主表的数据期间识别账期。保存方案并完成检验后，填写业务确认人、勾选确认，再关账。未通过节点需要填写接受差异的业务说明；执行错误、数据已更新、方案未重新检验、主表期间不符时禁止关账。

每次关账生成不可覆盖的归档版本，保存方案 SQL、最终检验结果、确认记录、业务语义、数据源配置以及各表的本地数据快照。可查看最终版并下载完整 ZIP。归档目录为 `data/period-archives`，未包含模型服务密钥或管理员密码。

关闭当前月份后才能创建新账期。新账期继承方案和标准参考表，主表必须重新导入当月数据；上月工作文件另存于 `data/period-working`。管理员输入密码及重开原因，可从某月份最后归档版本恢复工作区，必须重新检验并确认后生成下一归档版本。当前有未关闭账期时不能重开其他月份。

策略文件夹（含展开卡片）和检验结果支持拖动节点排序，两个入口共用方案顺序。点击“保存方案”或结果页的“保存节点顺序”后，下次按新顺序执行；聚合卡不参与排序，运行中和已关账时不可排序。历史结果内容不随排序改写。

当前需求：**所有报表在一个工作区展示，数据仍按表独立存储；整个工作区维护一份汇总校验方案。**

## 运行

双击本目录 `start.cmd`，浏览器访问 http://127.0.0.1:8765 。双击 `stop.cmd` 停止服务。

源码包不包含虚拟环境、业务数据或真实模型配置。首次运行需在本机创建 `.venv` 并按 `requirements-lock.txt` 安装依赖。Ace 编辑器资源已固定在 `static/vendor/`，运行时不需要 Node 或互联网。

“数据源”页为每张表分别连接本地文件夹，并按该表配置的文件名条件发现最新 Excel。点击“刷新最新数据”会在后台重新导入，无需停止服务。

## 当前可用功能

- **统一数据总览**：结算前、结算后及后续报表在同一页面展示，不再切换空间。
- **SQL 工作台**：Ace 语法高亮、字段补全、格式化、中文字段目录、Ctrl/⌘+Enter 执行、结果预览及完整行数。
- **真实 Wren 接入**：WrenAI 0.14.0 生成语义展开 SQL，实际查询本地只读 DuckDB；界面可展开查看规划结果。
- **单一汇总校验方案**：每个流程各自维护一段聚合校验 SQL，输入表固定为 `rule_detail`。每张表可配置任意多个校验节点，每个节点提供自己的明细 SQL。
- **拓展检验模式（可选，逐节点）**：节点可从默认「归零检验」切换为「拓展检验」，规则为「校验金额 `<` 或 `>` 阈值（元）」，按该节点校验金额合计判定通过。结果上方以万元报告实际值，报告文案可自定义（如「EMS收入：8,123.45 万元」）。通过/不通过的呈现与归零检验完全一致；节点导出模板升级为 v2，导入兼容 v1。
- **流程隔离**：每个流程只读取所属检验主表；标准参考表可供各流程使用。不同表的字段保持独立，不会自动映射。
- **运行结果**：按流程显示节点进度与结果。点击聚合结果可按当前节点的明细 SQL 回查对应数据。

旧版规则及运行历史保留在本地数据库中，但不再进入新版主流程。新版方案每次整体保存后版本号递增。

## 本地数据

业务报表、数据库、运行记录和模型服务配置保存在本机，不属于源码包。按本机数据目录连接文件夹并导入数据；真实模型配置请在本地填写，model-config.json 已加入忽略规则，不应提交到版本库。
## AI 配置

手工 SQL 和规则运行不依赖 AI。侧栏“AI 配置”可维护独立的模型服务，支持 OpenAI Responses、OpenAI Chat Completions 和 Anthropic Messages 协议，并提供连接测试。

可直接在页面填写配置，也可只读识别 `~/.cc-switch/cc-switch.db` 中的 CC Switch 供应商并选择导入。读取供应商列表不会修改 CC Switch；只有点击“导入”后，选中供应商的地址、模型、协议和密钥才写入本项目的 `model-config.json`。密钥不会通过 bootstrap 或供应商列表接口返回浏览器。

也可以将 `model-config.example.json` 复制为 `model-config.json`：

```json
{
  "base_url": "http://127.0.0.1:11434/v1",
  "model": "实际已部署模型名称",
  "api_key": "按服务要求填写",
  "api_format": "openai_chat"
}
```

也支持环境变量 `WREN_DEMO_LLM_BASE_URL`、`WREN_DEMO_LLM_MODEL`、`WREN_DEMO_LLM_API_KEY`。配置文件没有通过静态文件接口暴露，不要把密钥写进 SQL、前端或 Git。

“通用聚合 SQL”和“节点明细 SQL”编辑器内均有 AI 协作入口，可生成或修改 SQL、解释当前 SQL、根据执行报错修复。AI 只生成预览草稿，用户点击“应用到编辑器”后才会改动当前编辑内容；不会自动保存方案或运行校验。

生成节点 SQL 时，只发送工作区字段元数据、当前 SQL 和用户描述，不发送费用明细行。服务端强制检查 SQL 为只读查询、保留原始明细并输出“校验金额”。生成通用聚合 SQL 时，服务端先取得全部启用节点的输出字段契约，只把共同可用字段交给模型；生成后再逐个节点套用并进行 Wren 规划检查，任何节点不兼容都会拒绝草稿。业务信息不足时模型必须返回需要用户确认的问题。

## 技术与执行边界

前端是无构建依赖的 HTML/CSS/JavaScript；本地 API 使用 Python 标准库 HTTPServer；规则及运行记录存 SQLite；报表数据分别存 DuckDB；SQL 由本地 Wren Python SDK 规划。

数据源页可以新增任意数量的“校验主表”或“标准参考表”。创建时指定稳定的 SQL 表名，选择文件夹后由系统按文件名条件读取最新 Excel。已导入表都会进入同一个只读 SQL 工作区；节点内可用 `expense` 查询当前流程的主表，并与标准参考表关联；不可访问其他流程的检验主表。校验轨道独立于数据源，同一张主表可以创建多条进度条，参考表可以只参与查询而不建立进度条。

服务只监听 127.0.0.1，验证 Host 和 Origin，不开放外网。查询独立进程执行，30 秒超时，最多两个并发；DuckDB 只读、外部访问关闭。输入 SQL 和展开 SQL 均做结构检查，只允许当前模型/CTE及受支持函数。复杂方言或尚未开放函数会明确报错。

普通查询预览最多 500 行。节点判定会流式读取全部聚合结果。每个节点支持下载全部聚合、已选聚合、节点全部明细以及当前聚合分组对应明细。历史运行与当前数据指纹不一致时禁止重新导出。

## 代码位置

```text
close-validation-demo/
  start.cmd / stop.cmd       启停入口
  launch.py                 幂等启动、文件导入与浏览器打开
  import_data.py            Excel 数据导入与字段整理
  engine_adapter.py         Wren 模型、SQL 限制、只读执行
  query_worker.py           每次查询的独立进程
  server.py                 API、规则及运行记录、AI 草稿接口
  static/                   浏览器界面
  data/                     本地数据库、数据索引与账期归档（不会打包）
  logs/                     本地服务日志（不会打包）
  test_demo.py              真实数据集成检查，隔离测试状态库
  ARCHITECTURE.md            设计与后续扩展
```

Wren 安装来源为相邻 `WrenAI/core/wren`，本地提交基线 `19495ee`。未改动 Wren 仓库或原始报表。当前项目不依赖 Classic，不复制 Classic 源码。

测试命令：`.venv\Scripts\python.exe -m unittest test_demo -v`。

迁移到其他电脑需重建虚拟环境，安装 `requirements-lock.txt` 中依赖和相邻 Wren 源码包，再放置对应数据源。现有 `.venv` 依赖本机 Python 路径，不能直接复制后宣称可移植。

## Wren 用户与管理员入口

侧栏 Wren 语义入口和 SQL 编辑器右侧面板提供表/字段业务说明编辑，以及当前 SQL 规划预览。说明在本机 SQLite 保存，下次 AI 生成或澄清会读取；不会修改源字段类型。管理员入口通过服务端密码校验，提供执行参数设置、MDL 与实现查看；详细权限和后续工作见 EXPERIENCE_AUDIT.md。

### 节点明细与人工确认
勾选聚合行后下载已选明细，导出所选分组完整明细；未通过明细按完整校验结果导出。人工确认对本账期后续运行生效，可撤销；修改 SQL、容差或主表后需重新确认。历史运行不改写。菜单 SVG 来自 Lucide，许可证在 static/vendor/LUCIDE-LICENSE。首屏仅装载本账期最新运行，历史记录仍保留于数据库。

### 拖动交互
数据源折叠时只显示表头，拖动表头手柄自动保存数据源顺序。流程及节点排序保持为方案草稿，保存方案后生效。拖动直接使用 SortableJS 1.15.6 原版运行库的 fallback 跟手、animation 让位与 AutoScroll，许可证见 static/vendor/SORTABLE-LICENSE。业务适配代码位于 static/drag-ui.js。
